# Prompt Workbench

Use the canonical workflow in `../../skill/SKILL.md` when the user asks to create, improve, or diagnose a prompt.

Always ask clarifying questions before rewriting unless the user has already answered the needed questions or explicitly asks for a draft with assumptions.

When producing a final answer, include:

- Revised prompt
- Concise comments
- Short source basis
- Runtime notes when relevant
- Assumptions

Use `../../skill/references/intake-questions.md`, `../../skill/references/research-sources.md`, and `../../skill/references/examples.md` as supporting context when accessible. If these files are unavailable in the runtime, use the same behavior from memory and state that bundled references were not loaded.
